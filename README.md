# Data-Science-Tool-Mastery-Project
This project demonstrates practical data science skills using Pandas, NumPy, Matplotlib, Seaborn, and Scikit-learn, covering data cleaning, analysis, visualization, machine learning, and model evaluation.
Data Science Tool Mastery Project
Summary
This project demonstrates practical proficiency with commonly used Python data science libraries: Pandas, NumPy, Matplotlib, Seaborn, and Scikit-learn.
Objectives
- Practice data manipulation and analysis with Pandas and NumPy.
- Create charts and plots with Matplotlib and Seaborn.
- Build a basic machine-learning model using Scikit-learn.
- Showcase practical skills in a reproducible portfolio project.
Requirements
Install Python 3.8 or newer. Install dependencies:
pip install pandas numpy matplotlib seaborn scikit-learn
How to Run
1. Download data_science_tool_mastery.py.
2. Open Command Prompt/Terminal in the folder where it is saved.
3. Run:
python data_science_tool_mastery.py
On Windows, if needed, try:
py data_science_tool_mastery.py
Libraries Demonstrated
- Pandas: DataFrames, inspection, cleaning, filtering, grouping, CSV export.
- NumPy: Random data generation, vectorized operations, numerical calculations.
- Matplotlib: Figure creation, labels, titles, saving plots.
- Seaborn: Histograms, scatter plots, heatmaps, statistical visualization.
- Scikit-learn: Train/test split, standardization, linear regression, and model evaluation metrics.
Workflow
1. Generate a reproducible sample dataset about study habits and student scores.
2. Inspect data and summary statistics.
3. Handle missing attendance values using the median.
4. Create score categories and group summaries.
5. Visualize score distributions, feature relationships, and correlations.
6. Train a linear regression model to predict final scores.
7. Evaluate model using MSE, RMSE, and R-squared.
8. Export cleaned data and prediction results.
Output
The script creates a tool_mastery_outputs folder containing:
- practice_dataset_cleaned.csv
- model_predictions.csv
- score_distribution.png
- study_vs_score.png
- correlation_heatmap.png
- actual_vs_predicted.png
Note
The dataset is synthetically generated for learning purposes. It is not real student data.
